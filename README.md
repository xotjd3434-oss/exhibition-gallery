# MUSE SEOUL · Exhibition Gallery

> 다양한 전시 정보를 탐색하고 필터와 정렬 기능으로 원하는 전시를 찾는 전시 아카이브 웹사이트 | React · Vite

## 프로젝트 소개

MUSE SEOUL은 전시 포스터와 관람 정보를 함께 탐색하는 전시 큐레이션 프로젝트입니다. 작품을 발견하고 정보를 확인한 뒤 관심 전시에 저장하는 과정을 하나의 흐름으로 구성했습니다. 프로젝트 폴더명은 `exhibition-gallery`입니다.

이번 개편에서는 어두운 전시 공간을 모티브로 화면을 다시 구성했습니다. 전시장 사진과 포스터를 크게 보여주는 메인, 정보를 정리하는 가는 구분선, 여백이 있는 전시 목록으로 아카이브의 인상을 만들었습니다.

## 디자인 의도

차콜 배경 위에 작품과 포스터의 색이 드러나도록 구성했습니다. 텍스트는 따뜻한 화이트와 중간 회색으로 위계를 나누고, 세이지 색상은 분야·선택 상태 등 필요한 지점에 사용했습니다.

| 요소 | 적용 방향 |
| --- | --- |
| 배경 | 차콜 `#111213`, 전시 프레임 `#202223` |
| 텍스트 | 웜 화이트 `#EEEAE3`, 보조 텍스트 `#A1A3A0` |
| 포인트 | 세이지 `#B7C99B` |
| 메인 비주얼 | 전시장 사진 위 추천 전시 정보와 정면 포스터 배치 |
| 목록 | 데스크톱 3열, 태블릿·모바일 2열 포스터 프레임 |
| 정보 정리 | 얇은 구분선, 사각형 컨트롤, 일정한 카드 여백 |

## 전시 사이트 비교와 적용

- **국립현대미술관**: 현재·예정·과거 전시 구분과 장소·기간·유무료 조건 중심의 탐색 구조를 참고했습니다. 분야·지역·전시 상태·무료 필터를 하나의 탐색 영역으로 정리했습니다.
- **Whitney Museum**: 현재 전시와 예정 전시를 구분하고 전시명과 기간을 연결하는 정보 구조를 참고했습니다. 카드에서도 제목·상태·장소·기간의 순서를 일관되게 구성했습니다.

위 사이트의 정보 구조를 참고했으며, 어두운 컬러와 화면 구성은 이 프로젝트의 디자인 방향으로 재해석했습니다. 참고 사이트의 전시 정보나 작품을 복제하지 않았습니다.

참고: [국립현대미술관 전시](https://www.mmca.go.kr/exhibitions/progressList.do?menuId=1010000000) · [Whitney 전시](https://whitney.org/exhibitions)

## 주요 구현

### 전시 정보가 먼저 보이는 메인

전시장 사진을 배경으로 추천 전시의 영문 제목과 한글 제목, 소개와 관람 일정을 배치했습니다. 포스터는 정면으로 보여주어 그래픽을 읽을 수 있도록 구성했습니다. 추천 전시는 비주얼 아래쪽 좌우에 배치한 <, > 버튼으로 수동 전환합니다. 자동 전환과 인디케이터, 재생·정지 버튼을 제거해 조작 요소를 간결하게 정리했습니다.

### URL로 관리하는 검색 조건

18개 예시 전시 데이터에 키워드 검색과 분야·지역·상태·무료 조건을 조합합니다. 추천순, 최신 오픈순, 종료 임박순, 낮은 가격순으로 정렬할 수 있습니다. 검색 조건은 URL 쿼리로 관리해 같은 주소로 조건을 다시 불러올 수 있도록 구성했습니다.

### 관심 전시와 상세 연결

반복되는 카드를 공통 컴포넌트로 관리하고 목록과 상세 페이지에서 같은 저장 상태를 사용합니다. localStorage에 전시 ID를 보관해 새로고침 후에도 관심 전시가 유지되도록 처리했습니다. 상세 화면에는 같은 분야의 다른 전시를 연결했습니다.

### 반응형과 상태 표현

화면 너비에 따라 포스터 열 수, 메인 비주얼 배치, 필터 줄바꿈을 조정했습니다. 검색 결과 없음과 저장 목록 없음 상태를 별도로 안내하고 버튼 상태와 저장 안내에 접근성 속성을 적용했습니다. 본문 바로가기, 키보드 포커스 표시, 동작 줄이기 스타일도 구성했습니다.

## 사용 기술

React · Vite · JavaScript · CSS · React Router · localStorage

## 작업하며 정리한 점

전시 사이트에서는 이미지의 크기뿐 아니라 제목·장소·기간의 정보 순서가 탐색 경험에 영향을 준다는 점에 집중했습니다. 어두운 배경에서도 보조 정보가 읽히도록 텍스트 밝기를 나누고 포스터의 색을 유지하면서 주변 UI를 차분하게 정리했습니다.

공통 카드와 전시 데이터를 분리하고 URL 검색 조건과 저장 상태를 연결하는 과정을 통해 여러 페이지에 걸친 탐색 흐름을 구성했습니다.

## 프로젝트 안내

전시명·공간명·일정·요금 등은 포트폴리오 화면 구현을 위한 예시이며 실제 개최·예매 정보가 아닙니다. 기존 MUSE-SEOUL 저장소의 배포 경로는 유지했습니다. 다른 저장소에 배포할 경우 vite.config.js의 base를 해당 저장소 이름에 맞게 변경할 수 있습니다.

## 화면 정리

로고 옆 영문 설명, 추천 전시 상단 라벨과 분야·지역 문구, 비주얼 아래 아카이브 탐색 바, 목록 옆 보조 문구를 삭제했습니다. 화살표는 상하좌우 방향만 사용합니다.
